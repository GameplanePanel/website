## Dev containers

The repository ships one dev container profile per area, so a container installs only what your change needs. Pick it in VS Code with "Dev Containers: Reopen in Container", or under "Dev container configuration" in Codespaces; the full profile is the default.

<DocsSectionList
  items={[

The [profile table in docs/contributing.md](https://github.com/GameplanePanel/Gameplane/blob/master/docs/contributing.md#dev-container-profiles) lists what each profile installs, its setup time, and when to use it. A Make target that needs a missing tool stops with a `need:` message naming the profile to reopen in.
