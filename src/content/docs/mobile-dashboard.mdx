Gameplane works on mobile devices. The mobile dashboard prioritizes triage and navigation over dense forms, raw logs, and destructive operations — use desktop for those tasks.

<DocsCallout icon="gamepad-2" title="Mobile is for triage and navigation">
  Use desktop for dense forms, raw logs, credentials, confirmations, restores, and irreversible actions.
</DocsCallout>

## Know the boundary

Current mobile is designed for triage and navigation, not console, files, configuration, restore, or danger-zone work. These workflows require the desktop dashboard to ensure safe operation.
