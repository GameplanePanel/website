## Promote and migrate

Promote manifests and modules through GitOps; move worlds only through verified backup and restore.

Promote `Cluster` CRs, `GameTemplate`, and `Module` manifests through version control and argocd or flux deployments. Worlds and persistent game data migrate through the backup and restore subsystem:

1. **Export** the source GameServer's configuration (template, mods, ownership).
2. **Create a Backup** on the source cluster targeting a repository accessible from the target.
3. **Restore** the backup on the target cluster, validating the target cluster exists and target endpoints (RCON, streaming address) are reachable.
4. **Update ownership** to confirm the migrated server belongs to the intended user or team.
