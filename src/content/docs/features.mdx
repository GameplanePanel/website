Every Gameplane capability, grouped by area. The same list lives in the main repository as [FEATURES.md](https://github.com/GameplanePanel/Gameplane/blob/master/FEATURES.md), and a CI check keeps the two in step.

Maturity labels: **stable** (shipped, on by default, and exercised by a bucketed end-to-end test), **beta** (shipped with caveats or without a bucketed end-to-end test), **experimental** (shipped but the docs say so), **planned** (not started), **in progress** (started, not yet released).

Default column: **on** (enabled by the chart or the product), **off** (opt-in, ships disabled), or **n/a** (planned, in progress, or tooling with no install default).

Notification rows take effect once a notification sink is configured.

Status date: 2026-10-14 (v0.3.0, pre-v1). See the [roadmap](./roadmap/) for what is planned and in progress.
