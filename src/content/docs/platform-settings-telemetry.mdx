## Telemetry and privacy

Usage telemetry is an explicit choice and is not a substitute for operational metrics and logs.

When enabled, the API sends a daily anonymous report containing only the cluster version, count of active GameServers, and count of GameTemplates. The current implementation excludes server names, player counts, and identifying data.

## Updates and About

Update channel comes from Helm; record build hash, Kubernetes version, and license before troubleshooting or upgrading.

The Dashboard displays the current Gameplane version (from the container image tag, set via Helm `image.tag`), the Kubernetes cluster version, and internal build hash. This information is essential for support diagnostics and version-specific feature eligibility.

- **Version**: The image tag set at install time or on upgrade. Leave empty in Helm values to use the chart's `appVersion`.
- **Build hash**: The Git commit SHA from which the container images were built. Appears in logs and diagnostics.
- **Kubernetes version**: Your cluster's API server version, visible in Dashboard Settings → About and via `kubectl version`.

Before opening a support ticket or upgrading:

1. Record your Helm chart version, `image.tag`, and any custom `values.yaml` overrides
2. Confirm the Kubernetes version your cluster is running
3. Save the current Gameplane build hash from the Dashboard
4. If filing an issue, include these details to help narrow down version-specific bugs
