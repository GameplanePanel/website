## Override the image deliberately

Leave the field blank to inherit the template; a tested repository and immutable tag or digest is an explicit exception.

When you leave the image field blank, the server inherits the image selected by the template's version. A tested repository and immutable tag or digest is an explicit exception—pin an image only when you have a rollback path and have validated the version in your environment.
