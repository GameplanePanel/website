The Files, Players & Mods hub guides you through the three core day-to-day administration tasks: managing server files and directories, moderating players online, and installing or updating game mods and modpacks.

<DocsCallout icon="shield-alert" title="Back up before making irreversible changes">
  Back up world data before editing live files, changing a modpack, or running irreversible player actions. Use the Backup & Recovery tools to create snapshots before experiments.
</DocsCallout>

## Work with server files

Browse known server paths, create folders and files, upload assets, and edit text configuration in place. The file manager enforces path isolation and prevents accidental symlink escapes.

## Install mods and modpacks

Choose a registry, allow-listed URL, upload, or game-specific ID flow, then verify loader compatibility. Mods are installed into a manifest file that persists across restarts and can be version-controlled.
