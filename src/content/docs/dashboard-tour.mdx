The dashboard brings every server you are authorized to see into one view. Start from the fleet overview, narrow it with filters, and open a server to work on it.

<DocsCallout icon="milestone" title="Multi-cluster view in v0.3.0">
  In v0.2.0-beta.8 a top-bar cluster selector scopes every list, metric, and action to one cluster. From v0.3.0 the dashboard, Servers, Backups and Search combine every registered cluster you can access, and an optional Location filter narrows them.
</DocsCallout>

## Orientation

Opening a server pins it to its own cluster and namespace, so changing a list filter never retargets the server you are working on.
