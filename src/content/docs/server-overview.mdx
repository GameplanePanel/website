## Check game state and quick actions

Save and communicate before changing world state, files, mods, versions, restores, or player-facing rules.

<DocsCallout icon="info" title="World state changes need a backup and notice.">
  Before modifying save files, mods, or server config, ensure a backup is recent and any players are offline. Post a maintenance window notice or stop the server first.
</DocsCallout>
